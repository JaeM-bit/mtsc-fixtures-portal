How to Get the Best out of the Portal

The Highest Avg Net Points / Match takes all points FOR less all points AGAINST for each team and divides by the number of matches played, hence the view showing % matches played is an important factor. The highest possible score is 6.

Use the filter box to filter by column, team, opponent, date, status etc. Then try partial text, e.g. Jul will show only July matches. Hit the Home button below that and it will show July home matches, then try hitting Booked. That will add only the booked matches to the view and so on.

Also filter by team to see all matches for a specific team and use further filters if you only want to see Booked.

One of the filters is Matches in Next Days. If you type in 4 here, you will see all Milford teams' matches in the next 4 days. You can then filter more as above.
